# Documentos — Semana 01

Material de referencia y apoyo para la semana 01.

---

## Qué va en esta carpeta

Archivos de consulta que el estudiante puede usar durante y después de la semana:

- Cheatsheets de comandos Git
- Diagramas de la arquitectura Medallón
- Comparativa de formatos de datos (CSV / JSON / Parquet / Avro)
- Notas de clase o grabaciones enlazadas
- PDFs o presentaciones del instructor

---

## Cómo contribuir

Si añades material aquí, asegúrate de que:
1. El nombre del archivo sea descriptivo (ej. `cheatsheet_git.md`, no `documento1.pdf`)
2. Los archivos de datos grandes van en Google Drive, no aquí
3. Haz PR con prefijo `docs/` hacia `develop`
