## Qué va en esta carpeta

Archivos de consulta para PySpark avanzado y análisis del dataset financiero:

- Cheatsheet de funciones PySpark (transformaciones, window functions, fechas)
- Esquema del modelo de datos del dataset Financial Transactions
- Diagramas de JOINs con ejemplos del dataset
- Notas de clase o grabaciones enlazadas

## Cómo contribuir

Si añades material aquí, asegúrate de que:
1. El nombre del archivo sea descriptivo (ej. `cheatsheet_pyspark.md`, no `documento1.pdf`)
2. Los archivos de datos grandes van en Google Drive, no aquí
3. Haz PR con prefijo `docs/` hacia `develop`
