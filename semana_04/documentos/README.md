## Qué va en esta carpeta

Archivos de consulta para pipelines metadata-driven y Databricks Jobs:

- Referencia de `dbutils` (widgets, notebook, fs, secrets)
- Guía de estructura de archivos YAML para configuración de pipelines

## Cómo contribuir

Si añades material aquí, asegúrate de que:
1. El nombre del archivo sea descriptivo (ej. `referencia_dbutils.md`)
2. Los archivos de datos grandes van en Google Drive, no aquí
3. Haz PR con prefijo `docs/` hacia `develop`
