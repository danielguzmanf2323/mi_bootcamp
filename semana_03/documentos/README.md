# Documentos — Semana 03

Material de referencia y apoyo para la semana 03.

---

## Qué va en esta carpeta

Archivos de consulta para SQL avanzado sobre tablas Delta:

- Cheatsheet de Spark SQL (sintaxis, funciones de ventana, CTEs)
- Tabla de equivalencias PySpark ↔ SQL
- Ejemplos de EXPLAIN y lectura del plan de ejecución
- Notas de clase o grabaciones enlazadas
- PDFs o presentaciones del instructor

---

## Cómo contribuir

Si añades material aquí, asegúrate de que:
1. El nombre del archivo sea descriptivo (ej. `equivalencias_pyspark_sql.md`)
2. Los archivos de datos grandes van en Google Drive, no aquí
3. Haz PR con prefijo `docs/` hacia `develop`
